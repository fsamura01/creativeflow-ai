function App() {

      {result && (

          <p>Engagement: {result.mentor.engagement}/10</p>
          <p>{result.mentor.suggestions}</p>

# Why We're Doing This Before IBM Granite

A common mistake is connecting directly from React to an AI service.

By introducing the backend first, you gain several advantages:

* You keep API keys secure.
* You can change AI providers later without changing the frontend.
* You can add logging, validation, or caching.
* Your architecture is easier to explain in your README and demo.
